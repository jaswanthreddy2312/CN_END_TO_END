🎓 Viva / Examination Reference

1. Forward Secrecy & Ratchet: A one-way symmetric KDF chain ratchets message keys on each send, immediately erasing past message keys from memory. Conversational turns perform asymmetric DH ratcheting to refresh root key entropy.

2. Authenticated Encryption: AES-256-GCM computes a 128-bit authentication tag over the ciphertext. If any byte is altered in flight, the tag fails verification and the message is rejected.

3. Zero-Knowledge Relay: The backend WebSocket server authenticates users via JWT and routes encrypted envelopes without possessing the plaintext or private keys.
